# ControlRecord 0.1.6

0.1.6 為刪除、開始錄製、停止及執行腳本加入垃圾桶、錄製圓點、停止方塊與播放三角形圖示；保留文字，停用時圖示顯示為灰色。

0.1.5 將浮動狀態條縮小為 280 × 52 邏輯像素，採用 82% 不透明度。左側把手可拖曳，其餘區域滑鼠穿透；本次開啟程式期間保留拖曳位置，拖曳操作不寫入腳本。

0.1.4 加入右上角浮動錄製提示：3 秒倒數、錄製時間、事件數及 F8／F12 提示。狀態條保持最上層且滑鼠可穿透。錄製成功啟動時播放 Windows 提示音，可取消「錄製開始時播放提示音」；若系統靜音或未設定提示音則不會發聲。

0.1.3 修正深色 Windows 主題下確認框與提示視窗的文字對比，統一使用淺底深色文字。更新後請重新啟動程式。

Python 製作的 Windows 滑鼠錄製／重播工具，適合在固定位置的應用程式視窗中操作。

0.1.2 加入腳本刪除、可選錄影，並調整通用文案與淺色介面。保留先前修正：滑鼠移至螢幕邊緣時可能自動停止錄製的問題。真正因環境改變而中斷時，會保存已錄製內容、顯示停止原因並寫入日誌。更新現有版本後需先關閉程式再重新開啟，右上角應顯示 `v0.1.2`；既有腳本與影片可繼續使用。

## 開啟程式

開啟 `ControlRecord.exe`（原始碼專案中位於 `dist/ControlRecord/`）。整個資料夾需一起保留，不必另外安裝 Python。

若使用 ZIP，請先全部解壓縮至可寫入的資料夾，再開啟 EXE。程式資料儲存在 EXE 同一層的 `data`，不需安裝服務、不修改系統電源計畫。

開發原始碼版本可使用根目錄的 `start.cmd`；首次建立環境請執行 `setup.cmd`。

## 錄製

1. 將目標程式調整到預計使用的位置、大小與起始畫面。
2. 輸入腳本名稱，按「開始錄製」。未輸入名稱時自動使用日期時間命名。
3. 準備倒數 3 秒後，工具會縮小；接著操作目標程式。
4. 按 **F8** 結束，腳本自動儲存並出現在左側列表。

支援移動、左／右／中鍵、雙擊、拖曳、垂直及水平滾輪。雙擊與拖曳由原始按下／放開事件與時間間隔重現。錄製最後一個動作至按 F8 之間的等待也會保存。

若按住滑鼠時結束錄製，腳本會補上放開事件。工具本身的按鈕點擊不會寫入腳本。第一版不支援側鍵與鍵盤動作錄製。

## 執行與錄影

1. 選取左側腳本。
2. 設定總執行次數，以及延遲的時／分／秒。預設延遲 3 秒，可設為 0。
3. 將目標程式準備到與錄製時相同的起始畫面，選擇是否勾選「執行時錄製螢幕影片」，按「執行腳本」。
4. 倒數結束後工具縮小並開始重播；勾選錄影時，會等待錄影就緒。
5. 結束後，到「執行紀錄」選取該次任務，按「播放影片」。

未勾選錄影時，只保存腳本快照與執行結果，不產生影片。錄影預設勾選。啟用錄影時，一次任務的所有重複輪次共用一個 MP4。影片為全螢幕、原始解析度、20 FPS、H.264、包含游標、不錄音。倒數時間不錄影。若希望每輪之間等待，錄製結尾需保留所需等待時間；若重複執行，流程結尾應回到下一輪所需的起始狀態。

按 **F12** 可取消倒數、結束錄製或停止重播。正在重播時會先停止輸入、釋放工具按住的按鍵，再保存影片。保存期間可能需要等待幾秒；長影片可能更久。

工具開啟期間，F8 與 F12 保留給工具，不會傳入目標程式。其他鍵盤輸入不會被記錄或保存。

## 使用條件

- 目標環境：Windows 10 22H2／Windows 11，64 位元，單螢幕。實測範圍見 `TESTING.md`。
- 使用固定螢幕座標；目標程式視窗的位置、大小、內部解析度需與錄製時一致。
- 工具會檢查螢幕解析度、Windows 縮放與螢幕數量；不會自動恢復目標程式視窗位置，也不會自動辨識目標程式內部畫面。
- 執行時請讓目標程式保持可見，避免其他視窗遮住，並避免手動操作滑鼠。第一版不是背景控制模式。
- 系統或目標程式負載高時可能影響動作時間與畫面載入速度；固定時間重播不會等待畫面元素出現。
- 若目標程式以系統管理員身分執行，而點擊沒有反應，可讓此工具使用相同權限。一般情況先使用一般權限。
- 防休眠在工具開啟期間生效；「保持螢幕亮起」預設開啟，可取消。退出時解除電源請求。它不會阻止手動休眠、關機、合蓋或系統鎖定政策。
- 第一版可錄製至 500,000 個事件或約 7 天，先達到上限者停止並保存。實際可錄製時間取決於滑鼠移動事件數量。

## 檔案與故障排查

```text
data/
  scripts/<腳本ID>.json
  settings.json
  application.log
  runs/<時間與識別碼>/
    script.json            本次執行使用的腳本快照
    result.json            完成次數、狀態、錯誤與影片路徑
    screen.mp4             完成的影片
    screen.ffmpeg.log      錄影診斷資訊
```

腳本可透過每列的「刪除」按鈕移除，需確認；不會刪除既有執行紀錄與影片。腳本可透過「匯入／匯出」搬移。匯入會產生新的 ID，不覆蓋現有腳本。影片與紀錄會持續保存，沒有自動刪除功能；可用「開啟資料夾」管理磁碟空間。

錄影採用 `screen.partial.mkv` 中間檔，正常停止後封裝為 MP4。如果封裝失敗，會保留 MKV 並顯示提示，可嘗試以支援 MKV 的播放器觀看。正常的 F12 中止會產生 MP4；斷電、磁碟故障或強制結束無法保證影片完整。若上次未正常結束，可直接開啟該次資料夾尋找中間檔。

啟用錄影時，若錄影無法啟動，工具不會開始重播。若錄影中斷、超過 10 秒沒有新影格、桌面鎖定、螢幕設定改變或快捷鍵監聽失效，工具會停止操作。可查看 `screen.ffmpeg.log` 和 `application.log` 排查原因。
